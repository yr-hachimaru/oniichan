En el proceso de intentar llegar a conectar la Obsidian con un repositorio de Github mediante el comunity plugin Git, me encontré con que no me dejaba marchar el proceso de commit-and-sync, sin ser posible asimismo realizar push ni pull de manera individual. El caso es que me obligaba a poner unas credenciales que desconocía y las cuales no había configurado todavía porque no tenía un [[certificado SSH]] que utiliar. De tal modo, el primer paso que tenía que llevar a cabo era generar el certificado SSH. La vía de código que usé es la siguiente

    i:\home\albertoperezruiz> ssh-keygen -t rsa -b 4096 -C 
    diime.peerez@gmail.com
    
    Generating public/private rsa key pair.
    Enter file in which to save the key (/home/albertoperezruiz/.ssh/id_rsa): 
    Created directory '/home/albertoperezruiz/.ssh'.
    Enter passphrase for "/home/albertoperezruiz/.ssh/id_rsa" (empty for no passphrase): 
    Enter same passphrase again: 
    Your identification has been saved in /home/albertoperezruiz/.ssh/id_rsa

    Your public key has been saved in /home/albertoperezruiz/.ssh/id_rsa.pub
    The key fingerprint is:
    SHA256:vQ+TIHv6UauWa0AhAOdZjXMbSBqUCvs99N82W1trWKg diime.peerez@gmail.com
    The key's randomart image is:
    +---[RSA 4096]----+
    |.o=+o+           |
    |.o.== =          |
    |.o+  + +         |
    |o   . o  .       |
    | . o o. S o  .   |
    |  . o oo o +. .  |
    |     ..ooo*..o.  |
    |       o=oE=.o.. |
    |      .++o.oo..  |
    +----[SHA256]-----+

Llegado este punto, había generado una clave de SSH. Mediante la siguiente línea de código, comprobé si estaba funcionando. el hecho de que apareciera el "Agent pid xxxxx" demuestra que funciona:

    i:\home\albertoperezruiz> eval "$(ssh-agent -s)"
    Agent pid 10843

El siguiente objetivo era incluir la clave privada de SSH al agente para evitar que saltara todo el rato la ventana de autenticación. De esta manera, se podía evitar estar constantemente introduciendo contraseñas o que fallara el proceso (como había ocurrido previamente).
    
    i:\home\albertoperezruiz> ssh-add ~/.ssh/id_rsa.pub
    @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
    @         WARNING: UNPROTECTED PRIVATE KEY FILE!          @
    @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
    Permissions 0644 for '/home/albertoperezruiz/.ssh/id_rsa.pub' are too open.
    It is required that your private key files are NOT accessible by others.
    This private key will be ignored.

Desgraciadamente, los permisos de la clave eran demasiado permisivos, valga la redundancia. El hecho de que apareciera el código 0664 significa que efectivamente son un colador, en sentido figurado. Vamos a comprobar con el siguiente código que esto es así:

    i:\home\albertoperezruiz> ls -la ~/.ssh/
    total 8
    drwx------. 1 albertoperezruiz albertoperezruiz   42 jul 29 18:36 .
    drwx------. 1 albertoperezruiz albertoperezruiz  614 jul 29 18:27 ..
    drwx------. 1 albertoperezruiz albertoperezruiz   58 jul 29 18:32 agent
    -rw-------. 1 albertoperezruiz albertoperezruiz 3434 jul 29 18:27 id_rsa
    -rw-r--r--. 1 albertoperezruiz albertoperezruiz  748 jul 29 18:27 id_rsa.pub

Ese -rw-------. indica que está resguardado (lo que equivaldría a 600), mientras que el rw-r--r-- indica que está expuesto (lo que equivaldría al 664 previamente mencionado). Entonces, hay que cambiar la manera en que protegemos nuestra clave a algo más robusto. Utilizaremos el nombre del archivo donde se encuentra nuestra clave, que es id_rsa.pub
    
    i:\home\albertoperezruiz> chmod 600 ~/.ssh/id_rsa.pub
    
Volvemos a hacer vista completa para ver que efectivamente el tipo de seguridad ha cambiado al 600.
    
    i:\home\albertoperezruiz> ls -la ~/.ssh/
    total 8
    drwx------. 1 albertoperezruiz albertoperezruiz   42 jul 29 18:36 .
    drwx------. 1 albertoperezruiz albertoperezruiz  614 jul 29 18:27 ..
    drwx------. 1 albertoperezruiz albertoperezruiz   58 jul 29 18:32 agent
    -rw-------. 1 albertoperezruiz albertoperezruiz 3434 jul 29 18:27 id_rsa
    -rw-------. 1 albertoperezruiz albertoperezruiz  748 jul 29 18:27 id_rsa.pub
